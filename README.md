# Python cho người mới bắt đầu

Giáo án tiếng Việt dành cho người chưa từng học lập trình.

Đọc bài: https://phucluu-091005.github.io/python-for-economics/

## Thực hành trên GitHub Codespaces

1. Đăng nhập GitHub, chọn **Code → Codespaces → Create codespace on main**.
2. Chờ cài thư viện xong. Mở **Terminal → New Terminal**.
3. Chạy `python hello.py`.
4. Tạo file riêng cho mỗi bài, lưu và chạy `python ten_file.py`.
5. Bấm file `bieu_do.png` trong Explorer để xem biểu đồ.

Nếu thiếu thư viện, chạy `python -m pip install -r requirements.txt` ở Terminal.
Lưu bài về máy hoặc repository riêng trước khi xóa Codespaces. Dừng Codespaces sau buổi học tại https://github.com/codespaces.

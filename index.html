Cách sử dụng giáo án

Học tuần tự và chỉ đánh dấu hoàn thành sau khi tự gõ lại ví dụ, sửa một vài con số, giải bài tập mà chưa xem đáp án, rồi giải thích kết quả bằng lời. Mỗi bài tập có kết quả mong đợi, 2 gợi ý và đáp án. Mở lần lượt Gợi ý 1 và Gợi ý 2 trước khi xem đáp án. Code đáp án chạy được trong một file riêng. Đánh dấu tiến độ được lưu trong trình duyệt bạn đang dùng (nếu cho phép lưu trữ).

Chuẩn bị: máy tính có Internet và tài khoản GitHub. Bạn sẽ viết và chạy Python trong GitHub Codespaces ngay trên trình duyệt, không cần cài Python trên máy. Website này để đọc bài; Codespaces là nơi thực hành.

Bắt đầu với GitHub Codespaces

  1. Đăng nhập GitHub, mở repository của giáo án. Chọn Code → Codespaces → Create codespace on main (hoặc bấm liên kết GitHub Codespaces ở trên rồi chọn Create codespace). Chờ môi trường chuẩn bị xong.
  2. Bạn sẽ thấy trình soạn thảo VS Code trong trình duyệt. Cột Explorer bên trái là danh sách file; vùng giữa dùng để viết code; Terminal là nơi gõ lệnh chạy chương trình. Mở Terminal bằng menu Terminal → New Terminal.
  3. Mở file hello.py, sửa câu chào và nhấn Ctrl+S (Mac: ⌘S). Trong Terminal, gõ python hello.py rồi nhấn Enter. Kết quả hiện ở Terminal.
  4. Để học bài 2, chọn New File trong Explorer, đặt tên bai02.py, gõ ví dụ, lưu rồi chạy python bai02.py. Mỗi ví dụ nên có file riêng. Chỉ sao chép mã Python vào file; các lệnh bắt đầu bằng python bên dưới được gõ ở Terminal.
  5. Nếu chương trình hỏi thông tin bằng input(), bấm vào Terminal, gõ câu trả lời rồi Enter. Nếu muốn dừng chương trình đang chạy, nhấn Ctrl+C trong Terminal.
  6. Các thư viện sẽ được cài khi tạo Codespaces. Nếu thấy ModuleNotFoundError, chạy python -m pip install -r requirements.txt trong Terminal rồi chạy lại file. File CSV và ảnh kết quả nằm trong Explorer; bấm vào ảnh để xem, hoặc nhấp chuột phải vào file và chọn Download.
  7. Kết thúc buổi học, lưu file. Muốn giữ bài lâu dài, tải file về máy hoặc lưu vào repository riêng của bạn; bạn không có quyền đẩy bài lên repository giáo án của người khác. Vào Your codespaces, chọn dấu … → Stop codespace. Lần sau mở lại codespace cũ để tiếp tục.

Codespaces có hạn mức sử dụng theo tài khoản; thời gian chạy và dung lượng lưu trữ được tính riêng. Dừng khi không học để tiết kiệm thời gian chạy; file chưa đưa lên GitHub có thể mất nếu codespace bị xóa. Xem hướng dẫn hạn mức của GitHub.

Python là gì? Chạy chương trình trên Codespaces

Mục tiêu: Hiểu chương trình, môi trường chạy và thực thi lệnh đầu tiên
1. Khái niệm
Python là ngôn ngữ lập trình bậc cao: ta viết chỉ dẫn bằng cú pháp gần ngôn ngữ tự nhiên, trình thông dịch thực thi chúng.
2. Giải thích và cách dùng

Chương trình là một danh sách chỉ dẫn cho máy tính, giống công thức nấu ăn: làm bước 1 rồi bước 2. Trong Codespaces, mở hello.py, gõ ví dụ bên dưới và lưu file. Mở Terminal → New Terminal, gõ python hello.py rồi Enter. print() yêu cầu máy hiển thị kết quả. Dòng đầu in câu chào; dòng thứ hai tính một phép nhân. Khi có lỗi, đọc dòng cuối của thông báo, kiểm tra dấu ngoặc, dấu nháy và tên file rồi chạy lại.

3. Ví dụ minh họa
Ví dụ chạy được
print("Xin chào, mình đang học Python!")
print(120_000 * 2)
4. Bài tập tự luyện
  1. Sửa câu chào trong hello.py để in tên của bạn. Ví dụ với tên An:
    Kết quả mong đợi
    Xin chào, mình là An!
    Gợi ý 1

    Giữ nguyên print(). Chỉ thay phần chữ nằm giữa hai dấu nháy.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    print("Xin chào, mình là ___!")
    Đáp án
    print("Xin chào, mình là An!")

    Vì sao: Chữ trong dấu nháy là chuỗi, Python in nguyên văn. Thiếu một dấu nháy sẽ gây SyntaxError.

  2. Một sản phẩm giá 79.000đ. Dùng Python tính số tiền mua 3 sản phẩm.
    Kết quả mong đợi
    237000
    Gợi ý 1

    Phép nhân trong Python dùng dấu *. Viết số không có dấu chấm ngăn cách: 79000 hoặc 79_000.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    print(___ * ___)
    Đáp án
    print(3 * 79_000)

    Vì sao: Python hiểu 79.000 là số thập phân 79.0. Dấu gạch dưới _ chỉ giúp dễ đọc, Python bỏ qua nó.

Lưu ý: Không cần nhớ mọi cú pháp ngay. Thực hành từng ví dụ, tự thay số và đoán đầu ra trước khi chạy.
Nền tảng · Bài 02

Biến, kiểu dữ liệu và phép toán

Mục tiêu: Lưu số, chuỗi; tính doanh thu, lợi nhuận
1. Khái niệm
Biến là tên tham chiếu tới giá trị. int là số nguyên; float là số thực; str là chuỗi; bool là đúng/sai.
2. Giải thích và cách dùng

Dùng = để gán; + - * / // % ** là cộng, trừ, nhân, chia, chia lấy nguyên, lấy dư, lũy thừa. Python phân biệt dấu chấm thập phân với dấu phẩy hàng nghìn. Đơn vị phải nhất quán.

3. Ví dụ minh họa
Ví dụ chạy được
gia = 125_000
so_luong = 24
chi_phi = 1_800_000
doanh_thu = gia * so_luong
loi_nhuan = doanh_thu - chi_phi
print(f"Doanh thu: {doanh_thu:,.0f} VND")
print(f"Lợi nhuận: {loi_nhuan:,.0f} VND")
print(type(gia), type(0.075))
4. Bài tập tự luyện
  1. Một đơn hàng có 15 món, mỗi món giá 85.000đ. Cửa hàng chiết khấu 10% trên tổng tiền. Tính số tiền khách phải trả.
    Kết quả mong đợi
    Thanh toán: 1,147,500 VND
    Gợi ý 1

    Tổng tiền = giá × số lượng. Sau chiết khấu 10%, khách trả 90% tổng tiền, tức nhân với (1 - 0.10).

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    gia = 85_000
so_luong = 15
chiet_khau = 0.10
thanh_toan = ___
print(f"Thanh toán: {thanh_toan:,.0f} VND")
    Đáp án
    gia = 85_000
so_luong = 15
chiet_khau = 0.10
thanh_toan = gia * so_luong * (1 - chiet_khau)
print(f"Thanh toán: {thanh_toan:,.0f} VND")

    Vì sao: Trong f-string, :,.0f thêm dấu phẩy hàng nghìn và bỏ phần thập phân. Không có định dạng này, Python in 1147500.0.

  2. Giá vốn 60.000đ, giá bán 90.000đ. Tính biên lợi nhuận theo phần trăm, làm tròn 1 chữ số thập phân.
    Kết quả mong đợi
    Biên lợi nhuận: 33.3%
    Gợi ý 1

    Biên lợi nhuận = (giá bán − giá vốn) / giá bán. Nhân 100 để đổi sang phần trăm.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    gia_von = 60_000
gia_ban = 90_000
bien = (___ - ___) / ___ * 100
print(f"Biên lợi nhuận: {bien:.1f}%")
    Đáp án
    gia_von = 60_000
gia_ban = 90_000
bien = (gia_ban - gia_von) / gia_ban * 100
print(f"Biên lợi nhuận: {bien:.1f}%")

    Vì sao: Chia cho giá bán. Nếu chia cho giá vốn, kết quả là 50%: đó là tỷ lệ lãi trên giá vốn, một chỉ số khác.

Lưu ý: Biên lợi nhuận = (doanh thu − chi phí)/doanh thu; đừng nhầm với tỷ lệ lãi trên giá vốn.

Chuỗi, nhập liệu và chuyển kiểu

Mục tiêu: Nhận dữ liệu người dùng và làm sạch văn bản
1. Khái niệm
Chuỗi str chứa ký tự; input() trả về chuỗi kể cả khi gõ số.
2. Giải thích và cách dùng

int(), float() chuyển số; strip() xóa khoảng trắng hai đầu, lower() viết thường, replace() thay chuỗi. f-string chèn biến vào văn bản. Hãy kiểm tra dữ liệu trước khi tính.

3. Ví dụ minh họa
Ví dụ chạy được
ten = input("Tên cửa hàng: ").strip()
gia = float(input("Giá bán (VND): "))
print(f"{ten}: {gia:,.0f} VND")
ma = "  SKU-A01  "
print(ma.strip().lower())
4. Bài tập tự luyện
  1. Viết chương trình hỏi lương tháng, rồi in lương năm (12 tháng). Thử nhập 9000000.
    Kết quả mong đợi
    Lương tháng: 9000000
Lương năm: 108,000,000
    Gợi ý 1

    input() luôn trả về chuỗi. Dùng float() để đổi chuỗi thành số trước khi nhân.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    luong_thang = float(input("Lương tháng: "))
luong_nam = ___
print(f"Lương năm: {luong_nam:,.0f}")
    Đáp án
    luong_thang = float(input("Lương tháng: "))
luong_nam = luong_thang * 12
print(f"Lương năm: {luong_nam:,.0f}")

    Vì sao: Nếu bỏ float(), phép "9000000" * 12 lặp chuỗi 12 lần thay vì nhân số.

  2. Mã khách hàng nhập vào là " KH-002 ", có khoảng trắng ở hai đầu. Chuẩn hóa mã: bỏ khoảng trắng hai đầu và đổi thành chữ thường.
    Kết quả mong đợi
    kh-002
    Gợi ý 1

    strip() bỏ khoảng trắng hai đầu. lower() đổi sang chữ thường. Bạn có thể gọi nối tiếp hai phương thức.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    ma = "  KH-002  "
print(ma.___().___())
    Đáp án
    ma = "  KH-002  "
print(ma.strip().lower())

    Vì sao: Phương thức chuỗi trả về chuỗi mới, biến ma gốc không đổi. Muốn giữ kết quả, gán lại: ma = ma.strip().lower().

Điều kiện if, elif, else

Mục tiêu: Cho chương trình chọn hành động dựa trên điều kiện
1. Khái niệm
Điều kiện là biểu thức cho kết quả True hoặc False, dùng để điều khiển nhánh thực thi.
2. Giải thích và cách dùng

Các toán tử so sánh: == != > >= < <=. and/or/not kết hợp điều kiện. Thụt đầu dòng là một phần cú pháp Python; thường dùng 4 dấu cách.

3. Ví dụ minh họa
Ví dụ chạy được
doanh_so = 82_000_000
if doanh_so >= 100_000_000:
    thuong = doanh_so * 0.05
elif doanh_so >= 70_000_000:
    thuong = doanh_so * 0.03
else:
    thuong = 0
print(f"Thưởng: {thuong:,.0f}")
4. Bài tập tự luyện
  1. Cho loi_nhuan = -120000. In "Lãi" nếu lợi nhuận dương, "Lỗ" nếu âm, "Hòa vốn" nếu bằng 0. Sau đó đổi giá trị thành 50000 và 0 để thử hai nhánh còn lại.
    Kết quả mong đợi
    Lỗ
    Gợi ý 1

    Có 3 trường hợp, nên dùng if, elif và else.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    loi_nhuan = -120000
if loi_nhuan ___ 0:
    print("Lãi")
elif loi_nhuan ___ 0:
    print("Lỗ")
else:
    print("Hòa vốn")
    Đáp án
    loi_nhuan = -120000
if loi_nhuan > 0:
    print("Lãi")
elif loi_nhuan < 0:
    print("Lỗ")
else:
    print("Hòa vốn")

    Vì sao: else nhận mọi trường hợp còn lại. Ở đây chỉ còn trường hợp bằng 0.

  2. Đơn hàng từ 500.000đ trở lên được miễn phí vận chuyển. Đơn dưới 500.000đ chịu phí 30.000đ. Với đơn 420.000đ, in phí vận chuyển và tổng tiền.
    Kết quả mong đợi
    Phí vận chuyển: 30,000
Tổng tiền: 450,000
    Gợi ý 1

    "Từ 500.000đ trở lên" nghĩa là >= 500000. Tổng tiền = giá trị đơn + phí vận chuyển.

    Gợi ý 2: khung code

    Thay mỗi ___ bằng code phù hợp.

    gia_tri_don = 420_000
if gia_tri_don ___ 500_000:
    phi_ship = ___
else:
    phi_ship = ___
print(f"Phí vận chuyển: {phi_ship:,}")
print(f"Tổng tiền: {gia_tri_don + phi_ship:,}")
    Đáp án
    gia_tri_don = 420_000
if gia_tri_don >= 500_000:
    phi_ship = 0
else:
    phi_ship = 30_000
print(f"Phí vận chuyển: {phi_ship:,}")
print(f"Tổng tiền: {gia_tri_don + phi_ship:,}")

    Vì sao: Dùng >= vì đơn đúng 500.000đ cũng được miễn phí. Nếu dùng >, chương trình tính sai ở đúng mốc này. Thử đổi đơn thành 500000 để kiểm tra.

Vòng lặp for, while

Mục tiêu: Tự động hóa phép tính lặp đi lặp lại
1. Khái niệm
Vòng lặp lặp lại một khối lệnh. for phù hợp tập phần tử đã biết; while lặp khi điều kiện còn đúng.

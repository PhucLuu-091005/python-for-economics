Bắt đầu từ lệnh đầu tiên, học cách suy nghĩ theo từng bước rồi làm quen với dữ liệu, biểu đồ và dự án nhỏ. Không cần biết lập trình, Excel hay kiến thức chuyên ngành trước khi học. Bài nào cũng có khái niệm trước, ví dụ có thể chạy, bài tập và đáp án tự kiểm tra.

Cách sử dụng giáo án

Học tuần tự và chỉ đánh dấu hoàn thành sau khi tự gõ lại ví dụ, sửa một vài con số, giải bài tập mà chưa xem đáp án, rồi giải thích kết quả bằng lời. Đánh dấu tiến độ được lưu trong trình duyệt bạn đang dùng (nếu cho phép lưu trữ).

Chuẩn bị: máy tính có Internet và tài khoản GitHub. Bạn sẽ viết và chạy Python trong GitHub Codespaces ngay trên trình duyệt, không cần cài Python trên máy. Website này để đọc bài; Codespaces là nơi thực hành.

Bắt đầu với GitHub Codespaces

  1. Đăng nhập GitHub, mở repository của giáo án. Chọn Code → Codespaces → Create codespace on main (hoặc bấm liên kết GitHub Codespaces ở trên rồi chọn Create codespace). Chờ môi trường chuẩn bị xong.
  2. Bạn sẽ thấy trình soạn thảo VS Code trong trình duyệt. Cột Explorer bên trái là danh sách file; vùng giữa dùng để viết code; Terminal là nơi gõ lệnh chạy chương trình. Mở Terminal bằng menu Terminal → New Terminal.
  3. Mở file hello.py, sửa câu chào và nhấn Ctrl+S (Mac: ⌘S). Trong Terminal, gõ python hello.py rồi nhấn Enter. Kết quả hiện ở Terminal.
  4. Để học bài 2, chọn New File trong Explorer, đặt tên bai02.py, gõ ví dụ, lưu rồi chạy python bai02.py. Mỗi ví dụ nên có file riêng. Chỉ sao chép mã Python vào file; các lệnh bắt đầu bằng python bên dưới được gõ ở Terminal.
  5. Nếu chương trình hỏi thông tin bằng input(), bấm vào Terminal, gõ câu trả lời rồi Enter. Nếu muốn dừng chương trình đang chạy, nhấn Ctrl+C trong Terminal.
  6. Các thư viện sẽ được cài khi tạo Codespaces. Nếu thấy ModuleNotFoundError, chạy python -m pip install -r requirements.txt trong Terminal rồi chạy lại file. File CSV và ảnh kết quả nằm trong Explorer; bấm vào ảnh để xem, hoặc nhấp chuột phải vào file và chọn Download.
  7. Kết thúc buổi học, lưu file. Muốn giữ bài lâu dài, tải file về máy hoặc lưu vào repository riêng của bạn; bạn không có quyền đẩy bài lên repository giáo án của người khác. Vào Your codespaces, chọn dấu … → Stop codespace. Lần sau mở lại codespace cũ để tiếp tục.

Codespaces có hạn mức sử dụng theo tài khoản; thời gian chạy và dung lượng lưu trữ được tính riêng. Dừng khi không học để tiết kiệm thời gian chạy; file chưa đưa lên GitHub có thể mất nếu codespace bị xóa. Xem hướng dẫn hạn mức của GitHub.

Cách học cho người mới: ưu tiên bài 1–8 trước. Các ví dụ mua sắm, chi tiêu hay doanh thu chỉ giúp minh họa phép tính; bạn không cần học kinh tế. Những phần dữ liệu và công thức nâng cao được học sau nền tảng.

Quy ước: số liệu trong bài đều là dữ liệu giả lập, phục vụ học tập, không phải kết quả nghiên cứu hay tư vấn đầu tư. Chú ý các đơn vị: đồng, triệu đồng và tỷ đồng không được cộng trực tiếp nếu chưa quy đổi.

Nhịp học gợi ý: mỗi buổi 25 phút đọc khái niệm + 40 phút gõ/chạy ví dụ + 40 phút làm bài tập + 15 phút ghi nhớ. Học chậm hơn hoặc nhanh hơn đều được.

Python là gì? Chạy chương trình trên Codespaces

Mục tiêu: Hiểu chương trình, môi trường chạy và thực thi lệnh đầu tiên
1. Khái niệm
Python là ngôn ngữ lập trình bậc cao: ta viết chỉ dẫn bằng cú pháp gần ngôn ngữ tự nhiên, trình thông dịch thực thi chúng.
2. Giải thích và cách dùng

Chương trình là một danh sách chỉ dẫn cho máy tính, giống công thức nấu ăn: làm bước 1 rồi bước 2. Trong Codespaces, mở hello.py, gõ ví dụ bên dưới và lưu file. Mở Terminal → New Terminal, gõ python hello.py rồi Enter. print() yêu cầu máy hiển thị kết quả. Dòng đầu in câu chào; dòng thứ hai tính một phép nhân. Khi có lỗi, đọc dòng cuối của thông báo, kiểm tra dấu ngoặc, dấu nháy và tên file rồi chạy lại.

3. Ví dụ minh họa
Ví dụ chạy được
print("Xin chào, mình đang học Python!")
print(120_000 * 2)

    Xem gợi ý / đáp án
    print("Xin chào, mình là An!")
  2. Tính số tiền 3 sản phẩm giá 79.000đ bằng Python.
    Xem gợi ý / đáp án
    print(3 * 79000)
Lưu ý: Không cần nhớ mọi cú pháp ngay. Thực hành từng ví dụ, tự thay số và đoán đầu ra trước khi chạy.

Biến, kiểu dữ liệu và phép toán

Mục tiêu: Lưu số, chuỗi; tính doanh thu, lợi nhuận
1. Khái niệm
Biến là tên tham chiếu tới giá trị. int là số nguyên; float là số thực; str là chuỗi; bool là đúng/sai.
2. Giải thích và cách dùng

Dùng = để gán; + - * / // % ** là cộng, trừ, nhân, chia, chia lấy nguyên, lấy dư, lũy thừa. Python phân biệt dấu chấm thập phân với dấu phẩy hàng nghìn. Đơn vị phải nhất quán.

3. Ví dụ minh họa
Ví dụ chạy được
gia = 125_000
so_luong = 24
chi_phi = 1_800_000
doanh_thu = gia * so_luong
loi_nhuan = doanh_thu - chi_phi
print(f"Doanh thu: {doanh_thu:,.0f} VND")
print(f"Lợi nhuận: {loi_nhuan:,.0f} VND")
print(type(gia), type(0.075))
4. Bài tập tự luyện
  1. Đơn hàng 15 món giá 85.000đ, chiết khấu 10%. Tính tổng thanh toán.
    Xem gợi ý / đáp án
    gia = 85000
so_luong = 15
print(gia * so_luong * (1 - 0.10))
  2. Giá vốn 60.000đ, giá bán 90.000đ. Tính biên lợi nhuận trên doanh thu.
    Xem gợi ý / đáp án
    gia_von, gia_ban = 60000, 90000
print((gia_ban - gia_von) / gia_ban * 100)
Lưu ý: Biên lợi nhuận = (doanh thu − chi phí)/doanh thu; đừng nhầm với tỷ lệ lãi trên giá vốn.

int(), float() chuyển số; strip() xóa khoảng trắng hai đầu, lower() viết thường, replace() thay chuỗi. f-string chèn biến vào văn bản. Hãy kiểm tra dữ liệu trước khi tính.

Điều kiện if, elif, else

Mục tiêu: Cho chương trình chọn hành động dựa trên điều kiện
1. Khái niệm
Điều kiện là biểu thức cho kết quả True hoặc False, dùng để điều khiển nhánh thực thi.
2. Giải thích và cách dùng

Các toán tử so sánh: == != > >= < <=. and/or/not kết hợp điều kiện. Thụt đầu dòng là một phần cú pháp Python; thường dùng 4 dấu cách.

3. Ví dụ minh họa
Ví dụ chạy được
doanh_so = 82_000_000
if doanh_so >= 100_000_000:
    thuong = doanh_so * 0.05
elif doanh_so >= 70_000_000:
    thuong = doanh_so * 0.03
else:
    thuong = 0
print(f"Thưởng: {thuong:,.0f}")
4. Bài tập tự luyện
  1. Phân loại lãi/lỗ/hòa vốn theo biến lợi nhuận.

if loi_nhuan > 0:
    print("Lãi")
elif loi_nhuan < 0:
    print("Lỗ")
else:
    print("Hòa vốn")
  2. Phí vận chuyển: đơn từ 500.000đ miễn phí, còn lại 30.000đ.
    Xem gợi ý / đáp án
    gia_tri_don = 420000
phi_ship = 0 if gia_tri_don >= 500000 else 30000
print(phi_ship)

Vòng lặp for, while

Mục tiêu: Tự động hóa phép tính lặp đi lặp lại
1. Khái niệm
Vòng lặp lặp lại một khối lệnh. for phù hợp tập phần tử đã biết; while lặp khi điều kiện còn đúng.
2. Giải thích và cách dùng

range(1, 13) sinh từ 1 đến 12. break thoát vòng lặp; continue bỏ qua lượt hiện tại. Tránh while vô hạn.

3. Ví dụ minh họa
Ví dụ chạy được
doanh_thu_thang = [12, 15, 13, 18, 21, 25]
tong = 0
for i, doanh_thu in enumerate(doanh_thu_thang, start=1):
    print(f"Tháng {i}: {doanh_thu} triệu")
    tong += doanh_thu
print("Tổng:", tong, "triệu")
4. Bài tập tự luyện
  1. Tính tổng chi phí từ 1 tới 10 triệu theo danh sách [1,2,...,10].
    Xem gợi ý / đáp án
    tong = 0
for so in range(1, 11):
    tong += so
print(tong)
  2. Vốn ban đầu 10 triệu tăng 5%/năm. Tính vốn sau 5 năm bằng vòng lặp.
    Xem gợi ý / đáp án
    von = 10_000_000
for nam in range(5):
    von *= 1.05
print(round(von))

Danh sách, tuple, set và dictionary

Mục tiêu: Tổ chức dữ liệu nhiều đối tượng
1. Khái niệm
list lưu dãy có thứ tự và thay đổi được; tuple tương tự nhưng bất biến; set giữ phần tử không trùng; dict ánh xạ khóa → giá trị.
2. Giải thích và cách dùng

Chỉ số bắt đầu từ 0. Có thể lấy list[1:3], append() để thêm. dict.get(k, mặc_định) giảm lỗi khi thiếu khóa.

3. Ví dụ minh họa
Ví dụ chạy được
gia = [100, 120, 115, 130]
print(gia[0], gia[-1], sum(gia) / len(gia))
san_pham = {"ten": "Sổ tay", "gia": 35000, "ton_kho": 80}
print(san_pham["ten"], san_pham.get("giam_gia", 0))
print(set(["HN", "HCM", "HN"]))

print(max(ds), sum(ds)/len(ds))

    sp = {"ten":"Bút", "gia":5000, "so_luong":200}
print(sp["gia"] * sp["so_luong"])

Hàm và phạm vi biến

Mục tiêu: Viết lại logic có thể tái sử dụng
1. Khái niệm
Hàm là một khối lệnh có tên, nhận tham số, có thể trả về kết quả bằng return.
2. Giải thích và cách dùng

Đặt tên thể hiện công việc. return trả giá trị để tính tiếp, còn print chỉ hiển thị. Viết docstring để giải thích đầu vào/đầu ra; giới hạn phạm vi biến trong hàm.

3. Ví dụ minh họa
Ví dụ chạy được
def tinh_loi_nhuan(doanh_thu, chi_phi):
    """Trả về lợi nhuận tính bằng VND."""
    return doanh_thu - chi_phi

def tinh_bien_ln(doanh_thu, chi_phi):
    if doanh_thu == 0:
        return None
    return tinh_loi_nhuan(doanh_thu, chi_phi) / doanh_thu
print(tinh_loi_nhuan(5_000_000, 3_100_000))
print(tinh_bien_ln(5_000_000, 3_100_000))
4. Bài tập tự luyện
  1. Viết hàm tính thuế theo tỷ lệ đầu vào, trả tổng sau thuế.
    Xem gợi ý / đáp án
    def sau_thue(gia, thue_suat):
    return gia * (1 + thue_suat)
print(sau_thue(100000, 0.08))
  2. Viết hàm ROI = (thu về − vốn đầu tư)/vốn đầu tư; xử lý vốn bằng 0.
    Xem gợi ý / đáp án
    def roi(thu_ve, von):
    return None if von == 0 else (thu_ve - von)/von
print(roi(12_000_000, 10_000_000))
Nền tảng · Bài 08

Lỗi, kiểm tra đầu vào và debug

Mục tiêu: Đọc lỗi và xử lý dữ liệu không hợp lệ
1. Khái niệm
Exception là lỗi khi chương trình chạy, ví dụ ValueError khi chuyển chữ thành số, ZeroDivisionError khi chia cho 0.
2. Giải thích và cách dùng

Traceback chỉ vị trí lỗi. try/except dùng khi dự đoán thao tác có thể thất bại; không được dùng except trống để che mọi lỗi. assert và các kiểm tra giúp xác nhận giả định.

3. Ví dụ minh họa
Ví dụ chạy được
def nhap_so_duong(van_ban):
    try:
        so = float(van_ban)
        if so <= 0:
            raise ValueError("Phải lớn hơn 0")
        return so
    except ValueError as loi:
        print("Dữ liệu không hợp lệ:", loi)
        return None
print(nhap_so_duong("125000"))
print(nhap_so_duong("abc"))
4. Bài tập tự luyện
  1. Bọc phép chia doanh thu/đơn hàng, tránh số đơn bằng 0.
    Xem gợi ý / đáp án
    def gia_tri_don_trung_binh(doanh_thu, so_don):
    if so_don <= 0:
        return None
    return doanh_thu / so_don
print(gia_tri_don_trung_binh(1000000, 0))
  2. Kiểm tra giá không âm, ném ValueError nếu sai.
    Xem gợi ý / đáp án
    def kiem_tra_gia(gia):
    if gia < 0:
        raise ValueError("Giá không thể âm")
    return gia
print(kiem_tra_gia(12000))
Làm việc với dữ liệu · Bài 09

Đọc/ghi CSV và cấu trúc file

Mục tiêu: Lưu dữ liệu bảng như một file xuất từ Excel
1. Khái niệm
CSV là file văn bản dạng bảng, mỗi dòng là một bản ghi; có header tên cột.
2. Giải thích và cách dùng

Dùng pathlib cho đường dẫn, csv.DictReader/DictWriter cho dữ liệu. Mở file encoding="utf-8-sig" có thể xử lý BOM của một số file Excel. Ví dụ tạo file mẫu trước để chạy độc lập.

3. Ví dụ minh họa
Ví dụ chạy được
import csv
from pathlib import Path
tep = Path("doanh_thu_mau.csv")
with tep.open("w", newline="", encoding="utf-8-sig") as f:
    w = csv.DictWriter(f, fieldnames=["thang", "doanh_thu"])
    w.writeheader()
    w.writerows([{"thang": 1, "doanh_thu": 12000000}, {"thang": 2, "doanh_thu": 15000000}])
with tep.open("r", newline="", encoding="utf-8-sig") as f:
    for dong in csv.DictReader(f):
        print(dong["thang"], int(dong["doanh_thu"]))
4. Bài tập tự luyện
  1. Tạo CSV danh sách 3 khoản chi, sau đó đọc và tính tổng.
    Xem gợi ý / đáp án

with open("chi_phi.csv", encoding="utf-8") as f:
    ds = list(csv.DictReader(f))

Lưu ý: Không mở file CSV bằng cách tách chuỗi thủ công theo dấu phẩy: giá trị có thể chứa dấu phẩy trong dấu nháy.

Dữ liệu thiếu, trùng và ngoại lệ

Mục tiêu: Làm sạch dữ liệu trước khi kết luận
1. Khái niệm
Giá trị thiếu là quan sát không có thông tin; bản ghi trùng là nhiều dòng biểu diễn cùng một sự kiện; ngoại lệ là giá trị khác biệt bất thường.
2. Giải thích và cách dùng

isna(), drop_duplicates(), fillna(), to_numeric(errors="coerce") là công cụ chính. Không tự động thay dữ liệu thiếu bằng 0: chưa biết giá trị khác với giá trị bằng 0.

3. Ví dụ minh họa
Ví dụ chạy được
import pandas as pd
df = pd.DataFrame({"ma":[1,2,2,3], "chi_tieu":["100", None, None, "5000"]})
print("Thiếu:", df.isna().sum().to_dict())
df = df.drop_duplicates(subset=["ma"])
df["chi_tieu"] = pd.to_numeric(df["chi_tieu"], errors="coerce")
print(df, "Trung vị:", df["chi_tieu"].median())
4. Bài tập tự luyện
  1. Đếm ô dữ liệu thiếu từng cột.
    Xem gợi ý / đáp án
    print(df.isna().sum()) # Chạy sau ví dụ
  2. Thay giá trị chi_tieu thiếu bằng trung vị (chỉ với mục đích minh họa).
    Xem gợi ý / đáp án
    df["chi_tieu"] = df["chi_tieu"].fillna(df["chi_tieu"].median())
print(df)
Lưu ý: Ghi lại mọi bước làm sạch trong báo cáo. Bất thường có thể là biến động thực, không nhất thiết là lỗi.

Lãi kép, NPV, IRR và ROI

Mục tiêu: Ứng dụng Python trong tài chính căn bản
1. Khái niệm
Giá trị hiện tại là giá trị dòng tiền tương lai sau chiết khấu. NPV là tổng giá trị hiện tại của dòng tiền (gồm vốn đầu tư ban đầu). IRR là suất chiết khấu khiến NPV bằng 0.
2. Giải thích và cách dùng

Ví dụ dùng hàm NPV không phụ thuộc thư viện; IRR dùng numpy_financial nếu đã cài. Dòng tiền đầu kỳ thường âm. NPV dương tại mức chiết khấu giả định là dấu hiệu hấp dẫn theo tiêu chí NPV, không đảm bảo thành công.

3. Ví dụ minh họa
Ví dụ chạy được
dong_tien = [-100_000_000, 35_000_000, 40_000_000, 45_000_000]
r = 0.10
npv = sum(cf / ((1+r)**t) for t, cf in enumerate(dong_tien))
print(f"NPV: {npv:,.0f} VND")
von = 10_000_000
print("Lãi kép sau 3 năm:", round(von * 1.07**3))
4. Bài tập tự luyện
  1. Dự án vốn 50 triệu, thu 30 triệu sau 1 năm và 30 triệu sau 2 năm; tính NPV với r=8%.
    Xem gợi ý / đáp án
    cf = [-50_000_000,30_000_000,30_000_000]
r = .08
print(sum(x/(1+r)**t for t,x in enumerate(cf)))
  2. Tính ROI cho vốn 100 triệu, thu về 125 triệu.
    Xem gợi ý / đáp án
    print((125_000_000 - 100_000_000)/100_000_000)
Lưu ý: IRR có thể có nhiều nghiệm hoặc không có nghiệm với dòng tiền đổi dấu nhiều lần; không dùng IRR làm tiêu chí duy nhất.

Lạm phát, tăng trưởng và chỉ số

Mục tiêu: Phân biệt danh nghĩa và thực tế
1. Khái niệm
Tốc độ tăng trưởng là mức thay đổi tương đối so với kỳ gốc. Giá trị thực điều chỉnh ảnh hưởng mức giá bằng chỉ số phù hợp.
2. Giải thích và cách dùng

Tăng trưởng % = (mới/cũ − 1) × 100; tăng trưởng kép năm (CAGR) = (cuối/đầu)^(1/số_năm) − 1. Khi dùng CPI: giá trị thực theo giá kỳ gốc = danh nghĩa × CPI_gốc/CPI_hiện_tại.

3. Ví dụ minh họa
Ví dụ chạy được
gdp = [1000, 1060, 1124]  # tỷ VND giả định
tang_truong = [(gdp[i] / gdp[i-1] - 1)*100 for i in range(1,len(gdp))]
print("Tăng trưởng (%):", tang_truong)
luong_danh_nghia = 15_000_000
cpi_goc, cpi_hien_tai = 100, 125
print("Lương theo giá kỳ gốc:", luong_danh_nghia*cpi_goc/cpi_hien_tai)
4. Bài tập tự luyện
  1. GDP 500 tăng lên 605 sau 2 năm: tính CAGR.
    Xem gợi ý / đáp án
    print((605/500)**(1/2)-1)
  2. Giá 2026 là 150.000đ, CPI gốc 100 và hiện tại 120; quy về giá gốc.
    Xem gợi ý / đáp án
    print(150000*100/120)
Lưu ý: Không đồng nhất mức tăng giá một sản phẩm với tỷ lệ lạm phát toàn nền kinh tế.

Tương quan và hồi quy tuyến tính

Mục tiêu: Đọc quan hệ giữa biến và dự đoán cơ bản
1. Khái niệm
Hồi quy tuyến tính ước lượng quan hệ trung bình giữa biến phụ thuộc y và biến giải thích x; hệ số góc thể hiện y đổi bao nhiêu khi x tăng 1 đơn vị trong mô hình.
2. Giải thích và cách dùng

Tương quan không hàm ý nhân quả. Hệ số có thể bị sai lệch khi bỏ sót biến quan trọng. Dùng numpy.polyfit để làm quen; bài chuyên sâu có thể dùng statsmodels cho sai số chuẩn, kiểm định.

3. Ví dụ minh họa
Ví dụ chạy được
import numpy as np
quang_cao = np.array([1,2,3,4,5], dtype=float)  # triệu
doanh_so = np.array([10,14,15,19,22], dtype=float)  # triệu
beta1, beta0 = np.polyfit(quang_cao, doanh_so, 1)
print(f"Ước lượng: doanh số = {beta0:.2f} + {beta1:.2f} * quảng cáo")
print("Dự đoán khi chi 6 triệu:", beta0 + beta1 * 6)
print("Tương quan:", np.corrcoef(quang_cao, doanh_so)[0,1])
4. Bài tập tự luyện
  1. Thay quảng cáo = [1,2,3,4], doanh số = [2,4,6,8], tìm đường thẳng.
    Xem gợi ý / đáp án
    import numpy as np
print(np.polyfit([1,2,3,4],[2,4,6,8],1))
  2. Giải thích bằng lời vì sao hồi quy quảng cáo và doanh số chưa chứng minh quảng cáo gây tăng doanh số.
    Xem gợi ý / đáp án
    Gợi ý: doanh số và quảng cáo có thể cùng tăng do mùa vụ, khuyến mãi hoặc nhu cầu thị trường.

Ngày tháng, chuỗi thời gian và rolling

Chuỗi thời gian gồm các quan sát gắn mốc thời gian. Rolling window là phép thống kê trong một cửa sổ kỳ gần nhất.
2. Giải thích và cách dùng

pd.to_datetime chuyển thành ngày. resample tổng hợp theo tuần/tháng khi DateTimeIndex. pct_change tính tăng trưởng theo kỳ, nhưng cần kiểm tra kỳ trước bằng 0.

3. Ví dụ minh họa
Ví dụ chạy được
import pandas as pd
df = pd.DataFrame({"ngay": pd.date_range("2026-01-01", periods=6, freq="MS"), "doanh_thu": [10,12,11,15,17,18]})
df["tang_truong"] = df["doanh_thu"].pct_change()
df["tb_3_thang"] = df["doanh_thu"].rolling(3).mean()
print(df)
4. Bài tập tự luyện
  1. Tính trung bình trượt 2 tháng của doanh thu mẫu.
    Xem gợi ý / đáp án
    df["tb_2_thang"] = df["doanh_thu"].rolling(2).mean()
print(df)

def npv(cashflows, rate):
    return sum(cf/(1+rate)**t for t, cf in enumerate(cashflows))
A = [-100, 60, 55]
B = [-100, 30, 90]
for r in [0.08, 0.10, 0.12]:
    print(f"r={r:.0%} | A={npv(A,r):.2f} | B={npv(B,r):.2f}")
